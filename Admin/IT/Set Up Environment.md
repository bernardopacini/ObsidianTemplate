## Instructions

1. Install homebrew using the following command (can take a while)
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

2. Add brew to the path (not permanent until later)
```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

## Miscellaneous Notes

- Use homebrew as the default software manager, when possible.
